Dhasarathan Tamilarasan — Portfolio Website

Files:
- index.html: responsive, single-page portfolio website.

Publish for a public portfolio URL using GitHub Pages:
1. Sign in to GitHub or create an account at https://github.com.
2. Create a new public repository named: dhasarathan-portfolio
3. Upload index.html from this folder to the repository root.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
6. Wait for deployment. GitHub will show a public URL, usually:
   https://YOUR-GITHUB-USERNAME.github.io/dhasarathan-portfolio/

Before publishing:
- Verify the work dates, project descriptions, phone number, and email.
- Replace “Add your LinkedIn profile URL here” with your actual LinkedIn URL.
- The site currently does not link directly to your PDF resume. If desired, upload the PDF into the same repository and add a link to it.
- Only publish information you are comfortable making public.
